# EmployeeCredentialsApp

Приложение позволяет управлять учетными данными сотрудников:
- создавать новых сотрудников;
- редактировать существующих;
- просматривать список и детали сотрудников;
- удалять сотрудников;
- экспортировать список сотрудников в Excel.

Приложение построено с использованием Dependency Injection и реализует паттерн UnitOfWork с репозиториями

## Технологии
- .Net 9
- WinForms
- Entity Framework Core
- SQLite
- ClosedXML

## Конфигурация
Приложение использует JSON-файл конфигурации appsettings.json для указания строки подключения к базе данных:

```JSON
{
  "ConnectionStrings": {
    "DefaultConnection": "Data Source=app.db"
  }
}
```

Приложение не требует ручной настройки: при первом запуске оно автоматически создаст файл базы данных, применит миграции и заполнит её тестовыми данными (сотрудники и должности).
